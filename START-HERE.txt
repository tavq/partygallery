모험가의 앨범 — GitHub 업로드 안내

이 ZIP은 GitHub에 올릴 수 있는 독립형 사이트 사본입니다.
ChatGPT 시안 사이트와 별개이며 한쪽을 수정해도 다른 쪽에 자동 반영되지 않습니다.
프로그램 설치나 빌드 없이 index.html을 열어 로컬에서도 볼 수 있습니다.
이미지·폰트 폴더를 포함한 모든 파일을 같이 보관하세요.

1. 처음 올리기
1) GitHub에서 New repository를 선택합니다.
2) 저장소 이름은 rpg-album 등 원하는 영문 이름으로 설정하고 Public으로 만듭니다.
   README를 추가해서 만들면 이후 Add file 메뉴를 찾기 쉽습니다.
3) ZIP을 압축 해제합니다. ZIP 파일 자체를 올리는 것이 아닙니다.
4) 저장소의 Add file > Upload files로 들어갑니다.
5) 압축을 푼 폴더 안의 파일과 assets, images 폴더를 함께 드래그합니다.
   저장소 첫 화면에서 index.html이 바로 보여야 합니다.
   바깥 폴더째 올려서 한 단계 깊어지지 않도록 주의하세요.
6) main 브랜치에 Commit changes(변경사항 저장)합니다.
7) Settings > Pages > Build and deployment로 갑니다.
8) Source: Deploy from a branch / Branch: main / Folder: /(root) > Save.
9) 배포가 끝나면 Pages에 표시된 Visit site로 접속합니다.
   주소는 보통 https://아이디.github.io/저장소이름/ 형태입니다.

2. 파일 역할
index.html: 12명과 몬스터 선택 메인 화면.
character.html: 인물별 감정·이벤트 상세 화면.
monsters.html: 몬스터 선택 화면.
style.css: 디자인과 픽셀 폰트 적용.
app.js: 클릭, 화면 표시, 이미지 연결 동작. 일반적으로 수정할 필요 없습니다.
settings.js: 사이트 제목, 인물 이름, 글자색 설정.
assets: 픽셀 폰트와 폰트 라이선스.
images: 버튼과 상세 이미지. 아래 이름 규칙을 사용합니다.
.nojekyll: 일반 정적 파일로 배포하도록 하는 설정.
UPLOAD-HERE.txt: 해당 폴더의 이미지 번호 안내. 남겨둬도 됩니다.

3. 버튼 이미지
images/buttons/01.webp = 첫 번째 인물 버튼 (현재 티라)
images/buttons/02.webp = 두 번째 인물 버튼
...
images/buttons/12.webp = 열두 번째 인물 버튼
images/buttons/monster.webp = 메인 화면의 가로로 긴 몬스터 버튼

권장 버튼 크기: 인물 600x450px (4:3), 몬스터 1200x200px (6:1).
상세 원본은 인물 1400x1000px, 몬스터 1500x950px 그대로 사용할 수 있습니다.
버튼은 프레임에 맞춰 잘릴 수 있고, 상세 화면은 원본 비율 전체를 보여줍니다.

4. 인물 상세 이미지
images/characters/인물번호/종류-번호.webp
인물번호는 01~12입니다. 한 자리 숫자는 앞에 0을 붙입니다.
예: 첫 번째 인물(티라)의 통상 = images/characters/01/emotion-01.webp
예: 첫 번째 인물(티라)의 기쁨 = images/characters/01/emotion-02.webp
예: 두 번째 인물의 전투 = images/characters/02/event-01.webp
예: 열두 번째 인물의 결혼 = images/characters/12/event-10.webp
이 경로와 파일명대로 넣으면 HTML을 수정하지 않아도 표시됩니다.

6. 이름과 글자색 바꾸기
settings.js를 메모장이나 GitHub 편집 버튼으로 엽니다.
해당 인물의 name과 color만 바꿉니다. id는 이미지 폴더 번호이므로 유지하세요.
예: "name": "티라", "color": "#e99287"
사이트 제목은 SITE_TITLE을 수정합니다.
감정은 numbers에 실제 파일 번호를 지정합니다. 01~13 연속 번호입니다.
이벤트와 몬스터 순서는 이미지 번호와 연결되므로 임의로 재정렬하지 마세요.

7. 이미지를 교체하거나 추가하기
GitHub에서 해당 폴더로 들어간 뒤 Add file > Upload files로 올립니다.
같은 경로·파일명으로 올리면 교체됩니다. 기존 파일을 먼저 삭제할 필요는 없습니다.
새로고침 후에도 옛 그림이 보이면 Ctrl+F5로 새로고침하세요.
로컬 수정은 GitHub에 다시 업로드해야 공개 사이트에 반영됩니다.
현재 설정은 항목당 이미지 한 장입니다. 한 항목에 여러 장을 넣으려면 코드 변경이 필요합니다.

8. 확장자와 샘플
기본 형식은 소문자 .webp입니다. 없을 때 같은 이름의 .png를 시도합니다.
같은 번호에 webp와 png가 모두 있으면 webp를 보여줍니다.
실제 PNG 파일 이름의 확장자만 .webp로 바꾸지 마세요. 실제 형식과 맞춰주세요.
파일이 없으면 빈 슬롯/미등록 안내가 나옵니다.
티라 버튼과 통상, 고블린과 몬스터 배너에 예시 이미지를 넣었습니다.
고블린 예시는 01.png, 배너 예시는 monster.png입니다.
실제 01.webp, monster.webp를 추가하면 새 WEBP가 우선 표시됩니다.
윈도우 탐색기의 보기 > 표시 > 파일 확장명을 켜면 .webp.webp 같은 중복을 피할 수 있습니다.

9. 업로드 용량
GitHub 웹 업로드는 파일당 25MiB, 한 번에 최대 100개 파일입니다.
이 초기 패키지는 100개 미만이므로 한 번에 올릴 수 있습니다.
1.5~2MB짜리 이미지 수백 장은 인물 폴더별로 나눠 올리면 편합니다.
GitHub Pages 전체 사이트는 1GB 이하, 월 전송량은 100GB 소프트 한도입니다.
원본 파일은 따로 백업해 두고, 계속 분량이 늘면 외부 이미지 저장소를 고려하세요.
